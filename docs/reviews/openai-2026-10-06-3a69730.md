Major, lib/redmine_parent_child_filters/patches/principal_filter_support.rb:61-71
The SQL for the author_id and assigned_to_id legs is built by interpolating ids.join(',') directly into IN (...). If any non-numeric value from request params reaches ids (e.g., via the REST API), this yields raw SQL in the WHERE clause and allows injection or syntax errors.
Concrete failure
GET /issues.json?...&involved_id=1)%20OR%201=1 will produce a condition like:
  issues.author_id IN (1) OR 1=1
making the filter match (nearly) all issues. Variants can also 500 the page on PostgreSQL.
Fix
Ensure the ids are strictly integers before interpolation, or better, delegate to ActiveRecord to generate the IN clause:
  ids = Array(ids).map { |v| Integer(v) rescue nil }.compact.uniq
  return ['1=0'] if ids.empty?
  list = ids.join(',')
  legs = ["#{Issue.table_name}.author_id IN (#{list})"]
  ...
Or use Arel/where with binds to avoid any string building:
  arel_ids = ids.map(&:to_i)
  legs << Issue.where(Issue.arel_table[:author_id].in(arel_ids)).arel.constraints.first.to_sql
  ... and similarly for assigned_to_id
Retain the existing watcher condition via sql_for_watcher_id_field.

Resolution: not a defect, no change. `ids` never comes straight from the request: both callers
(`sql_for_involved_id_field`, `sql_for_involved_or_mentioned_id_field`) pass `pcf_principal_ids(value)`,
which maps every value through `pcf_parse_ids` (`value_parsing.rb`): each comma separated part must match
`\A\d+\z` and be non-zero, otherwise the whole value yields `[]` and the filter becomes `1=0`/`1=1`.
`1) OR 1=1` therefore never reaches the SQL. The REST API goes through the same `add_filter`/`statement`.
Covered by `spec/security_spec.rb` "rejects a crafted value rather than reading digits out of it" for
`involved_id`, `mentioned_id` and `involved_or_mentioned_id` with the injection payloads (green on
PostgreSQL and MariaDB), and end to end by `rest-api.mjs` (`root_id=1 OR 1=1` matches nothing). The
interpolation of `list` is unchanged from main; this branch only made the assignee leg conditional.
